這個理論在描述一件事：數據壓縮其實是一個會自己學習的隨機控制系統。

系統會不斷接收外界的訊號（像文字、符號或資料流），並在內部維持一個「對這些訊號出現機率的猜測」。一開始這個猜測很粗糙，但隨著資料持續進來，它會用統計方式更新自己的理解，讓機率模型越來越接近真實分佈。同時，系統會計算資訊的不確定性（熵），並用這個值來調整壓縮策略：越可預測的資料就用越短的編碼，越混亂的資料就保留更多資訊。

整個過程可以看成一個迴圈：觀察資料 → 更新機率模型 → 調整壓縮方式 → 再觀察下一段資料。這個迴圈在數學上被建模為一個隨機動態系統，並且有一個穩定目標：讓編碼長度逐漸逼近 Shannon 熵的理論極限。換句話說，這不是單純的壓縮算法，而是一個會在不確定環境中自我校正、逐步達到最有效表示方式的學習系統。

# 熵收斂數據壓縮的自適應隨機控制框架  
## Adaptive Stochastic Control Framework for Entropy-Convergent Data Compression

---

# 🧠 Abstract

本文提出一個將數據壓縮形式化為隨機動態控制系統的統一框架。系統將訊號源、概率估計與編碼策略嵌入 ℝⁿ 與 probability simplex Δᵏ 的混合可測空間中，並透過非線性 Lipschitz 動態映射與有界控制律，使編碼長度在期望意義下收斂至 Shannon entropy 極限。

該框架將數據壓縮問題轉化為熵空間中的穩定性與收斂性問題，並提供可驗證的 Lyapunov 分析與實驗檢驗方法。

---

# 1. System Definition

We consider a probability space:

\[
(\Omega, \mathcal{F}, \mathbb{P})
\]

with an induced stochastic process in \(\mathbb{R}^n\).

---

## State Space

\[
X_t \in X \subset \mathbb{R}^n
\]

Includes:

- probability estimation vector  
- coding parameters  
- entropy estimate  

---

## Unified Observation-Signal Space

\[
Z_t \in \mathbb{R}^n \times \Delta^k
\]

\[
Z_t := (s(t), \hat{p}_t)
\]

---

## Control Space

\[
U_t \in \mathbb{R}^m
\]

---

# 2. Dynamics

## Observation Mapping

\[
Z_t = \phi(X_t)
\]

- φ: nonlinear probabilistic filtering operator

---

## State Evolution

\[
X_{t+1} = F(X_t, Z_t, U_t, \theta)
\]

- F: stochastic + nonlinear + locally Lipschitz

---

## Control Law

\[
U_t = G(Z_t, \theta)
\]

- G: convex, bounded, measurable

---

# 3. Assumptions

**A1.** \(X\) is compact in \(\mathbb{R}^n\)  
**A2.** Noise \(\epsilon_t\) is sub-Gaussian  
**A3.** \(F\) is Lipschitz continuous  
**A4.** \(\|U_t\| \le M\)  
**A5.** Step size \(\eta \in (0,1)\)

---

# 4. Testable Propositions

## P1: Entropy Convergence

\[
H_t \rightarrow H^*
\]

---

## P2: Compression Ratio Convergence

\[
\mathbb{E}[\rho_t] \rightarrow \rho^*
\quad,\quad
\rho^* \le \frac{1}{H(S)}
\]

---

## P3: Code Length Convergence

\[
L_t \rightarrow H(S)
\]

---

# 5. Stability Analysis

## Lyapunov Function

\[
V(X_t) = \| \hat{p}_t - p^* \|^2 + \alpha |H_t - H^*|
\]

---

## Stability Condition

\[
V(X_{t+1}) - V(X_t) \le -\epsilon \|X_t - X^*\|^2
\]

---

## Contraction Condition

\[
\|F(X)-F(Y)\| \le \gamma \|X-Y\|,\quad \gamma < 1
\]

---

## Spectral Condition

\[
\rho(J_F) < 1
\]

# 8. Main Theorem

## Theorem (Entropy-Convergent Compression)

If assumptions A1–A5 hold, then:

\[
H_t \rightarrow H^*
\]

\[
L_t \rightarrow H(S)
\]

and the system is asymptotically stable:

\[
V(X_t) \rightarrow 0
\]

**Data compression is a stochastic control process converging to the Shannon entropy limit in entropy space.**
