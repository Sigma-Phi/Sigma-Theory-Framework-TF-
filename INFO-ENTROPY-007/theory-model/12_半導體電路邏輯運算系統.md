### 🧠 核心導讀
本系統將半導體物理層的電位變化視為資訊熵的載體。透過非線性開關行為（電晶體）構建確定性運算空間，在電壓波動與環境雜訊的壓力下，利用閾值濾波與時序同步維持邏輯一致性，實現從模擬物理態向數位符號態的有序映射。
### 1️⃣ 核心貢獻 (CORE CONTRIBUTION)
 * **1.1 Core Claim**: 系統通過定義「邏輯勢能屏障」(Logic Potential Barrier)，在極端電壓漂移與寄生電容干擾下，相比於傳統類比電路，實現了單位功耗下邏輯狀態維持機率的顯著提升。
 * **1.2 Problem Definition**: 系統目標是最小化邏輯轉換延遲 \Delta t 與錯誤率 \epsilon，在高頻開關壓力模型下，保證狀態轉移函數的確定性。

### 4️⃣ 主定理與推論 (MAIN THEOREM)
**定理：** 若物理環境雜訊強度 \xi < \frac{1}{2}(V_{high} - V_{low})，則存在一邏輯映射 M，使得輸出狀態序列 X_{out} 在 T 時間步長內滿足 P(X_{out} = X_{ideal}) \geq 1 - e^{-\lambda T}，其中 \lambda 為系統恢復係數。

### 6️⃣ PYTHON 模擬 (PYTHON SIMULATION)
```python
import numpy as np

def observe_state(voltage, threshold=2.5):
    """將物理電壓映射為邏輯狀態"""
    return 1 if voltage > threshold else 0

def logic_gate_step(state_vector, weights, threshold):
    """模擬邏輯閘陣列傳播"""
    potential = np.dot(weights, state_vector)
    next_state = [observe_state(p, threshold) for p in potential]
    return np.array(next_state)

# 系統初始參數
weights = np.array([[0.5, 0.8], [0.8, 0.5]]) # 耦合權重矩陣
state = np.array([0, 1])                     # 初始狀態
threshold = 1.0

# 模擬運算週期
for t in range(5):
    state = logic_gate_step(state, weights, threshold)
    print(f"Time {t}: State {state}")

```
